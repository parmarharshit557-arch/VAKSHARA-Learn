Math module: roots, powers and rounding

The math module supplies mathematical functions and constants. Distinguish ceil(), floor(), trunc() and round(): they follow different rules, especially for negative numbers.

Real-life example

The math module is a calculator drawer with specialised buttons for roots, powers and rounding. It saves you from rewriting those formulas yourself.

Step-by-step explanation

  1. sqrt(49) returns 7.0.
  2. ceil(4.2) returns the smallest integer greater than or equal to 4.2: 5.
  3. floor(4.8) returns the greatest integer less than or equal to 4.8: 4.

Python example

import math
print(math.sqrt(49))
print(math.ceil(4.2))
print(math.floor(4.8))

Expected output

7.0
5
4

Common mistake

ceil and floor are not the same as round. ceil always moves upward to an integer; floor moves downward.

Remember this

ceil = up; floor = down; sqrt = square root. Check the return type too.
