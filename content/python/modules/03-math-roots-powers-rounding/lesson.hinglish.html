Math module: roots, powers and rounding

math module mathematical functions aur constants deta hai. ceil(), floor(), trunc() aur round() ke rules alag hain; negative numbers par difference aur clear hota hai.

Real-life example

math module calculator drawer jaisa hai jisme roots, powers aur rounding ke special buttons hain. Formulas khud likhne ki zarurat kam hoti hai.

Step-by-step samjhaav

  1. sqrt(49) 7.0 return karta hai.
  2. ceil(4.2) 4.2 se bada ya equal sabse chhota integer deta hai: 5.
  3. floor(4.8) 4.8 se chhota ya equal sabse bada integer deta hai: 4.

Python example

import math
print(math.sqrt(49))
print(math.ceil(4.2))
print(math.floor(4.8))

Expected output

7.0
5
4

Common mistake

ceil aur floor, round ke same nahi. ceil upar integer par; floor neeche integer par le jaata hai.

Yaad rakho

ceil = upar; floor = neeche; sqrt = square root. Return type bhi check karo.
