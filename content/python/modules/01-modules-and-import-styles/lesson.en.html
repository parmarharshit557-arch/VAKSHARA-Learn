Modules and import styles

A module is a Python file that groups reusable code. import makes names from a module available, and different import styles affect how those names are referenced.

Real-life example

A module is like a toolbox. Instead of building every tool yourself, you import the toolbox and use the tool you need.

Step-by-step explanation

  1. import math makes the module available under the name math.
  2. math.sqrt accesses the square-root function through that module.
  3. randint is imported directly under the shorter alias roll. Its output varies.

Python example

import math
import random
from random import randint as roll
random.seed(7)
print(math.sqrt(25))
print(roll(1, 6))

Expected output

5.0
3

Common mistake

If you write import math, call math.sqrt(25). Calling sqrt(25) alone will not work unless you imported sqrt directly.

Remember this

Import the module, then use module.name; or import a chosen name directly.
