Local, global scope and return values

Scope describes where a name can be used. Functions can read global names, create local names and return results. Prefer parameters and return values over unnecessary global state.

Real-life example

A function is like a small work desk. Names created on that desk are local to the function. A global name is kept in the shared room outside the desk. A return value is the finished result handed back.

Step-by-step explanation

  1. price is a parameter and becomes local to the function call.
  2. tax is created locally; tax_rate is read from module scope.
  3. return sends 105.0 back to the caller.

Python example

tax_rate = 0.05
def total_with_tax(price):
    tax = price * tax_rate
    return price + tax

print(total_with_tax(100))

Expected output

105.0

Common mistake

print() displays a value; return sends a value back to the code that called the function. They are not interchangeable.

Remember this

Local belongs to the function call; return carries a result out.
