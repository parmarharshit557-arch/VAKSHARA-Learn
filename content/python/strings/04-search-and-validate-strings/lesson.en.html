Searching and testing text

Searching methods locate text or test whether a string has a particular form. Choose find() when a missing match should produce -1, and understand that index() raises ValueError when it cannot find the text.

Real-life example

Searching text is like checking whether a word appears on a page. Validation is like checking whether a form entry follows a simple rule before accepting it.

Step-by-step explanation

  1. in checks whether a substring exists.
  2. endswith() checks the ending of the string.
  3. find() returns the first matching index, or -1 when no match exists.

Python example

email = "asha@example.com"
print("@" in email)
print(email.endswith(".com"))
print(email.find("example"))

Expected output

True
True
5

Common mistake

find() can return -1. Do not treat -1 as a valid character position; check the result first.

Remember this

Search answers “where or whether?”; validation answers “does this text satisfy my rule?”.
