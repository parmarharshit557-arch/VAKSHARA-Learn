Searching and testing text

Search methods text ko locate karte hain ya check karte hain ki string kisi pattern ko follow karti hai. Match na mile toh find() -1 deta hai; index() match na milne par ValueError raise karta hai.

Real-life example

Text search page par word dhoondhne jaisa hai. Validation form entry ko accept karne se pehle rule check karna hai.

Step-by-step samjhaav

  1. in check karta hai ki substring present hai ya nahi.
  2. endswith() string ka ending check karta hai.
  3. find() first match ka index deta hai; match na mile toh -1.

Python example

email = "asha@example.com"
print("@" in email)
print(email.endswith(".com"))
print(email.find("example"))

Expected output

True
True
5

Common mistake

find() -1 bhi return kar sakta hai. -1 ko valid index mat samjho; pehle result check karo.

Yaad rakho

Search poochta hai “kahan / hai ya nahi?”; validation poochta hai “kya text mera rule follow karta hai?”
