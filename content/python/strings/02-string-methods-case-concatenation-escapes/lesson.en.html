String methods, case changes, joining and escape sequences

Python strings provide methods for changing letter case and useful operators for combining text. Escape sequences represent special characters such as a newline or tab.

Real-life example

String methods are like text tools: one changes letter case, one joins pieces, and escape sequences let you put a new line or tab inside text.

Step-by-step explanation

  1. upper() returns a new uppercase string.
  2. title() returns a title-cased string.
  3. \n represents a line break inside the string.

Python example

name = "asha"
print(name.upper())
print(name.title())
message = "Hello\nPython"
print(message)

Expected output

ASHA
Asha
Hello
Python

Common mistake

A string method returns a new string; it does not rewrite the original string in place.

Remember this

Methods act on text; save their returned value if you want to keep the transformed text.
