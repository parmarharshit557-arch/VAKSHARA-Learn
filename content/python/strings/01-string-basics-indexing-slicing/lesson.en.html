String basics, immutability, indexing and slicing

A string is an immutable sequence of Unicode characters. Indexing selects one character; slicing creates a new piece using start:stop:step, with the stop position excluded.

Real-life example

A string is like a row of letter tiles. Each tile has a position, so you can pick one character or take a slice of consecutive characters.

Step-by-step explanation

  1. Index 0 points to the first character P.
  2. Index -1 points to the last character N.
  3. Slice [1:4] starts at index 1 and stops before index 4: Y, T, H.

Python example

word = "PYTHON"
print(word[0])
print(word[-1])
print(word[1:4])

Expected output

P
N
YTH

Common mistake

Strings are immutable. You cannot do word[0] = "p"; create a new string with a method or slicing instead.

Remember this

Index picks positions; slicing picks a range; the stop index is excluded.
