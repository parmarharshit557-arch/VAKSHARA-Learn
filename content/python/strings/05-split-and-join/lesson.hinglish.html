Split and join strings

split() ek string ko pieces ki list mein todta hai. join() iska reverse karta hai: jis separator par call kiya hai, usse strings ko combine karta hai.

Real-life example

split() sentence ko spaces par todkar word cards banata hai. join() cards ko separator ke saath wapas jodta hai.

Step-by-step samjhaav

  1. split() words ki list return karta hai.
  2. Ab list mein teen string items hain.
  3. Separator string " | " un items ko ek string mein join karti hai.

Python example

sentence = "learn Python daily"
words = sentence.split()
print(words)
print(" | ".join(words))

Expected output

['learn', 'Python', 'daily']
learn | Python | daily

Common mistake

join() separator string par call hota hai aur items strings hone chahiye. Numbers ko join karna ho toh map(str, values) use karo.

Yaad rakho

split: ek string se list; join: strings ki list se ek string.
