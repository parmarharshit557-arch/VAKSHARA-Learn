Adding and removing set items

Sets can be updated using add() for one item and update() for multiple items from an iterable. remove() raises KeyError if absent; discard() does not.

Real-life example

A set is a club membership list. add() registers a member, discard() removes only if present without complaining, and remove() reports an error if the member is absent.

Step-by-step explanation

  1. add() inserts Mina if it is not already present.
  2. discard() removes Rohan if present and does nothing if it is absent.
  3. sorted() creates a predictable display order for this example.

Python example

members = {"Asha", "Rohan"}
members.add("Mina")
members.discard("Rohan")
print(sorted(members))

Expected output

['Asha', 'Mina']

Common mistake

set.pop() removes an arbitrary element; do not assume it removes the “last” or a particular item.

Remember this

add inserts; remove expects presence; discard is safe if absence is possible.
