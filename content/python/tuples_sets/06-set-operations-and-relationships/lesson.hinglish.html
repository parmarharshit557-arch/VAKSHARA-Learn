Set operations and relationships

Set operations mathematical relationships ko represent karte hain: union dono sets combine karta hai, intersection common items rakhta hai, difference left-only items, aur symmetric difference exactly ek set mein hone wale items rakhta hai.

Real-life example

Do school clubs ke members common ho sakte hain. Union = dono clubs ke sab unique members; intersection = dono mein common; difference = sirf pehle club ke members.

Step-by-step samjhaav

  1. | dono sets ke unique items combine karta hai.
  2. & sirf common items rakhta hai.
  3. - left set ke woh items rakhta hai jo right set mein nahi.

Python example

python = {"Asha", "Rohan", "Mina"}
sql = {"Mina", "Dev"}
print(sorted(python | sql))
print(sorted(python & sql))
print(sorted(python - sql))

Expected output

['Asha', 'Dev', 'Mina', 'Rohan']
['Mina']
['Asha', 'Rohan']

Common mistake

Difference directional hai: A - B zaroori nahi B - A ke equal ho.

Yaad rakho

Union = kisi bhi side; intersection = dono; difference = left only; symmetric difference = exactly ek side.
