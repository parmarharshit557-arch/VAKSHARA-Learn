Packing, unpacking and converting collections

Packing multiple values ko tuple mein group karta hai. Unpacking tuple items ko matching variables mein assign karta hai. Zarurat ke hisaab se list aur tuple convert kar sakte hain.

Real-life example

Packing kai values ko ek parcel mein rakhna hai. Unpacking parcel kholkar har item ko alag named variable dena hai.

Step-by-step samjhaav

  1. Tuple mein teen values hain.
  2. Unpacking first value name, second age, third course ko assign karta hai.
  3. Normally target names ki count values ke barabar honi chahiye; starred unpacking alag case hai.

Python example

student = ("Asha", 18, "CSE")
name, age, course = student
print(name)
print(age)
print(course)

Expected output

Asha
18
CSE

Common mistake

Teen values ko do names mein unpack karoge toh ValueError aayega. Remaining items collect karne ke liye starred target use hota hai.

Yaad rakho

Packing values ko group karta hai; unpacking names mein distribute karta hai.
