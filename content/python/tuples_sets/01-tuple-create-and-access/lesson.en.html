Tuple basics and accessing items

A tuple is an ordered sequence. It supports indexing, slicing, membership tests and iteration, but the tuple’s item references cannot be reassigned.

Real-life example

A tuple is like a printed appointment card: it stores a fixed group of values in order. You can read the fields, but you do not edit an item in place.

Step-by-step explanation

  1. The tuple stores three values in a fixed order.
  2. Index 0 selects Asha; index -1 selects the last item CSE.
  3. len() counts three items.

Python example

record = ("Asha", 18, "CSE")
print(record[0])
print(record[-1])
print(len(record))

Expected output

Asha
CSE
3

Common mistake

A one-item tuple needs a comma: (5,). Parentheses alone, (5), simply group an integer.

Remember this

Tuple = ordered and immutable. A comma creates a one-item tuple.
