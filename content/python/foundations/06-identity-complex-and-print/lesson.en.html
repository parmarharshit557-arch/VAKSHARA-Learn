Identity, swapping, complex numbers and output

This group connects object identity, multiple assignment, complex-number values and formatted output. One key distinction: equality compares values; identity asks whether two references point to the same object.

Real-life example

Equality is asking whether two notebooks contain the same answers. Identity is asking whether both names point to the very same physical notebook.

Step-by-step explanation

  1. a and b contain equal values, so == is True.
  2. They are separate list objects, so a is b is False.
  3. c refers to the same object as a, so a is c is True.
  4. sep changes the text printed between values.

Python example

a = [1, 2]
b = [1, 2]
c = a
print(a == b)
print(a is b)
print(a is c)

name, age = "Asha", 18
print(name, age, sep=" - ")

Expected output

True
False
True
Asha - 18

Common mistake

Do not use is to compare ordinary numbers or strings by value. Use == for equality; use is mainly for identity checks such as value is None.

Remember this

== asks “same value?”; is asks “same object?”.
