Data types and Python values

A variable stores a reference to a value. The value has a type, and that type determines which operations make sense. Start by recognising integers, floats, strings, booleans and complex numbers.

Real-life example

Think of a school bag: it can hold a book, a water bottle, a name card and a yes/no permission slip. They are all values, but they are different kinds of values.

Step-by-step explanation

  1. 18 is a whole number, so Python creates an int value.
  2. 1.65 has a decimal part, so its type is float.
  3. Text inside quotes is a str; True is a bool value.

Python example

age = 18
height = 1.65
name = "Asha"
is_student = True

print(type(age).__name__)
print(type(height).__name__)
print(type(name).__name__)
print(type(is_student).__name__)

Expected output

int
float
str
bool

Common mistake

Do not confuse 25 with "25". The first is a number you can calculate with; the second is text.

Remember this

Ask two questions: what value is stored, and what type is that value?
