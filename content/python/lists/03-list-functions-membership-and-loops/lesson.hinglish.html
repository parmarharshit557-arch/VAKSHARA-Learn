List built-ins, membership and loops

Built-in functions list ke baare mein common questions ka answer deti hain. Membership aur loops items inspect karte hain. Index aur value dono chahiye hon toh enumerate() useful hai.

Real-life example

List tasks ki queue jaisi hai. len count batata hai, in check karta hai task present hai ya nahi, loop har task visit karta hai.

Step-by-step samjhaav

  1. len() list ke items count karta hai.
  2. quiz present hai, isliye in True deta hai.
  3. Loop har item ko task variable mein rakhta hai aur body run karta hai.

Python example

tasks = ["read", "revise", "quiz"]
print(len(tasks))
print("quiz" in tasks)
for task in tasks:
    print(task)

Expected output

3
True
read
revise
quiz

Common mistake

List method aur built-in function same nahi. len(items) function hai; items.count(x) method hai.

Yaad rakho

Function ko list pass hoti hai: len(items). Method list ka hota hai: items.count(x).
