START FROM ZERO

List slicing

Slicing selects a range of items and returns a new list. The stop index is excluded, and a step can skip positions or reverse the direction.

Real-life example

Imagine a row of five seats. A slice selects a continuous set of seats by start and stop positions; the stop seat is not included.

Step-by-step explanation

  1. [1:4] starts at index 1 and stops before 4.
  2. [:3] uses the default start 0 and stops before 3.
  3. [::2] visits every second item.

Python example

colors = ["red", "blue", "green", "gold", "white"]
print(colors[1:4])
print(colors[:3])
print(colors[::2])

Expected output

['blue', 'green', 'gold']
['red', 'blue', 'green']
['red', 'green', 'white']

Common mistake

Remember that the stop index is excluded. This is why items[0:3] gives three items, not four.

Remember this

slice syntax is [start:stop:step]; the stop is a boundary, not a selected index.
