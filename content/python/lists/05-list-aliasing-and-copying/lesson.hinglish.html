Aliasing and copying lists

List assignment automatic copy nahi banata. Do variable names same object ko refer kar sakte hain (alias). copy(), slicing ya list() se shallow outer copy banayein; nested mutable objects ka difference bhi samjhein.

Real-life example

Ek hi storage box par do labels lagane se do boxes nahi bante. Agar dono names ek list ko point karte hain, kisi bhi name se change karne par same list change hoti hai.

Step-by-step samjhaav

  1. alias = original same list object ka second name banata hai.
  2. alias se append karne par original bhi change hota hai.
  3. copy() alag outer list banata hai; copy mein append original ko nahi badalta.

Python example

original = [10, 20]
alias = original
copy = original.copy()
alias.append(30)
copy.append(40)
print(original)
print(copy)

Expected output

[10, 20, 30]
[10, 20, 40]

Common mistake

Shallow copy outer list alag banata hai, lekin andar ki nested lists ko recursively copy nahi karta.

Yaad rakho

Assignment ek aur reference banata hai; copy() alag outer list banata hai.
