Nested loops and processing number digits

A nested loop places one loop inside another. Processing digits commonly uses remainder (%) to read the last digit and floor division (//) to remove it.

Real-life example

A nested loop is like rows and seats in a theatre. The outer loop chooses a row; the inner loop visits every seat in that row.

Step-by-step explanation

  1. The outer loop starts at row 1.
  2. The inner loop completes seats 1, 2 and 3 before the outer loop moves on.
  3. Then row 2 repeats the same inner sequence.

Python example

for row in range(1, 3):
    for seat in range(1, 4):
        print(row, seat)

Expected output

1 1
1 2
1 3
2 1
2 2
2 3

Common mistake

A nested loop can run many times: 2 outer rounds × 3 inner rounds = 6 prints here.

Remember this

The inner loop finishes all its rounds for each single outer-loop round.
