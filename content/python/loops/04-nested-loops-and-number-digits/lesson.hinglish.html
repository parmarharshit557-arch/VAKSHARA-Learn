Nested loops and processing number digits

Nested loop mein ek loop doosre loop ke andar hota hai. Number ke digits process karne ke liye % se last digit nikalte hain aur // se last digit hataate hain.

Real-life example

Nested loop theatre ki rows aur seats jaisa hai. Outer loop row choose karta hai; inner loop us row ki har seat visit karta hai.

Step-by-step samjhaav

  1. Outer loop row 1 se start hota hai.
  2. Inner loop seats 1, 2, 3 complete karta hai; tab outer loop next row par jaata hai.
  3. Row 2 ke liye inner loop phir se poora chalta hai.

Python example

for row in range(1, 3):
    for seat in range(1, 4):
        print(row, seat)

Expected output

1 1
1 2
1 3
2 1
2 2
2 3

Common mistake

Nested loops mein total repetitions multiply hote hain: yahan 2 outer × 3 inner = 6 prints.

Yaad rakho

Outer loop ke ek round ke andar inner loop apne saare rounds complete karta hai.
