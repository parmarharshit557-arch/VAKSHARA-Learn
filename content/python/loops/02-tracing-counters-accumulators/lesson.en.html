START FROM ZERO

Trace loops, counters and accumulators

A dry run follows variable values one iteration at a time. A counter tracks how many events occur; an accumulator keeps a running result such as a sum.

Real-life example

A counter is a tally mark that counts how many things happened. An accumulator is a running total in a notebook where you keep adding each new amount.

Step-by-step explanation

  1. Start total at 0.
  2. Add 2: total becomes 2.
  3. Add 4: total becomes 6; add 6: total becomes 12.

Python example

total = 0
for number in [2, 4, 6]:
    total += number
    print("running total:", total)
print("final:", total)

Expected output

running total: 2
running total: 6
running total: 12
final: 12

Common mistake

If total is meant to grow, do not reset it to 0 inside the loop. That would erase earlier work on every iteration.

Remember this

Counter usually changes by 1; accumulator collects a running result.
