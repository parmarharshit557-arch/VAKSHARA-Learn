BILKUL BASIC SE

break, continue and loop else

Ye statements loop ka normal flow change karte hain. break nearest loop se bahar nikalta hai, continue next iteration par le jata hai, aur loop else tab chalta hai jab loop break ke bina finish ho.

Real-life example

Class ki line mein kisi ek student ko current activity se skip karna continue jaisa hai. Puri activity rok dena break jaisa hai.

Step-by-step samjhaav

  1. 1 par dono conditions false hain, isliye 1 print hota hai.
  2. 2 par continue current iteration ka baaki code skip karta hai.
  3. 4 par break poora loop stop kar deta hai; 4 print nahi hota.

Python example

for number in range(1, 6):
    if number == 2:
        continue
    if number == 4:
        break
    print(number)

Expected output

1
3

Common mistake

break nearest loop ko exit karta hai; continue sirf current iteration skip karta hai. Dono ka kaam alag hai.

Yaad rakho

continue = ye round skip; break = loop band.
