Loop mistakes and input-controlled loops

Many loop bugs come from an unchanged condition, an off-by-one range or an update in the wrong place. Input-controlled loops often use a sentinel, a flag or while True with a deliberate break.

Real-life example

A repeat-until-exit menu is like a shop counter that stays open until the customer says “I am done”. The loop needs a clear stopping signal.

Step-by-step explanation

  1. choice starts as an empty string, so it is not equal to exit.
  2. The loop body runs and updates choice to exit.
  3. The condition is checked again; it is now False, so the loop stops.

Python example

choice = ""
while choice != "exit":
    choice = "exit"
print("Menu closed")

Expected output

Menu closed

Common mistake

Forgetting to update the control variable is a common cause of infinite loops. Also avoid changing the same list while iterating over it without a clear plan.

Remember this

Every input-controlled loop needs: initial value, repeated action, and a way to reach the stop condition.
