Truthy, falsy values and common mistakes

Python conditions accept more than literal True and False. Some values are falsy, such as 0, empty strings and empty collections; most other values are truthy. Branch order and indentation also matter.

Real-life example

A program often needs to decide whether something is present. An empty basket means “nothing here”; a basket with one apple means “something is here”. Python has the same idea for truth values.

Step-by-step explanation

  1. An empty list is falsy.
  2. An empty string is falsy.
  3. A non-empty list is truthy.

Python example

values = []
name = ""
subjects = ["Python"]
print(bool(values))
print(bool(name))
print(bool(subjects))

Expected output

False
False
True

Common mistake

Do not write if value == True when you only need a truth test. Usually write if value: or if not value:.

Remember this

Empty built-in containers and empty text are falsy; non-empty ones are truthy.
