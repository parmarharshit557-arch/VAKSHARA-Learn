Logical operators and nested conditions

Logical operators multiple conditions ko combine karte hain. Nested if mein ek decision ke andar doosra decision hota hai; inner check tabhi hota hai jab outer condition us tak pahunchti hai.

Real-life example

Nested decision building ke gates jaisa hai: pehle outer gate pass hoga, tabhi andar ka question check hoga.

Step-by-step samjhaav

  1. Outer if mein has_id True hai, isliye Python andar jaata hai.
  2. Andar inner if has_ticket ko check karta hai. Ye bhi True hai.
  3. Isliye Entry allowed print hota hai.

Python example

has_id = True
has_ticket = True
if has_id:
    if has_ticket:
        print("Entry allowed")
    else:
        print("Ticket needed")
else:
    print("ID needed")

Expected output

Entry allowed

Common mistake

Indentation decide karti hai ki kaunsa if kis ke andar hai. Galat indentation se else galat if ke saath attach ho sakta hai.

Yaad rakho

and = dono pass; or = kam se kam ek pass; nested if = ek decision ke andar doosra.
