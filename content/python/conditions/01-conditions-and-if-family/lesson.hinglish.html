Conditions and if statements

Condition aisi expression hoti hai jiska result True ya False hota hai. if, else aur elif ki madad se program decide karta hai ki kaunsa block run hoga.

Real-life example

Condition school gate ke sawal jaisi hai: “ID card hai?” Answer yes ho toh ek action, warna doosra path.

Step-by-step samjhaav

  1. Python pehle marks >= 90 check karta hai. Ye False hai.
  2. Phir marks >= 60 check hota hai. Ye True hai, isliye grade B set hota hai.
  3. Ek branch match ho gayi, isliye else run nahi hota.

Python example

marks = 72
if marks >= 90:
    grade = "A"
elif marks >= 60:
    grade = "B"
else:
    grade = "C"
print(grade)

Expected output

B

Common mistake

Sabse strict condition pehle rakho. Agar marks >= 40 pehle check karoge toh A wali condition kabhi nahi chalegi.

Yaad rakho

if pehla path check karta hai, elif agla, else bachi hui situation handle karta hai.
