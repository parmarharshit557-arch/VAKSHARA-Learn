Where and how can you run Python?

Python program likhne ke liye jagah aur run karne ke liye environment chahiye. Tumhare learning material mein Google Colab notebooks use hue hain, isliye pehle cells aur outputs samjhenge, phir local editor ka idea.

Real-life example

Notebook workbook jaisi hai jisme alag boxes hote hain. Ek cell mein chhota experiment likho, cell run karo aur result uske neeche dekho. First line try karne ke liye poora project banana zaroori nahi.

Step-by-step samjhaav

  1. Colab notebook open karke code cell par click karo.
  2. Yahan di gayi do lines type karo.
  3. Run button ya Shift + Enter se cell run karo.
  4. print ka output aur 2 + 3 ki value cell ke neeche dikhegi.
  5. Local setup mein wahi Python statements .py file mein save karke Python se run kar sakte ho.

Python example

print("First cell")
print(2 + 3)

Expected output

First cell
5

Common mistake

Cells ko out of order run karoge toh pehle define na hua variable missing ho sakta hai ya purani value ho sakti hai. Clean check ke liye fresh session mein Runtime → Run all use karo.

Yaad rakho

Cell mein likho → cell run karo → output padho. Notebook chhote experiments ke through seekhne deta hai.
