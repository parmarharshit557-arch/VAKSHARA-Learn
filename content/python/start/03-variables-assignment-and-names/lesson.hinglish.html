Variables: storing and reusing information

Variable kisi value ko naam deta hai taaki program use dobara use kar sake. Data types detail mein jaane se pehle assignment, reassignment, naming rules, case sensitivity aur dynamic typing samjho.

Real-life example

Variable notes mein labelled box jaisa hai. Label uska name hai; box ke andar jo hai woh value hai. Baad mein contents replace kar sakte ho, lekin label se value ko phir refer kar sakte ho.

Step-by-step samjhaav

  1. student_name name string value "Asha" ko refer karta hai.
  2. score pehle integer 72 ko refer karta hai.
  3. Next assignment score ki current value ko 85 se replace karta hai.
  4. Last assignment score ko string se bind karta hai. Python mein pehle type declare karna zaroori nahi.

Python example

student_name = "Asha"
score = 72
print(student_name, score)

score = 85
print(score)

score = "excellent"
print(score)

Expected output

Asha 72
85
excellent

Common mistake

Jab compare karna ho toh = nahi, == use karo. x jaise vague names ke bajaye total_marks jaise descriptive names code ko samajhna easy banate hain.

Yaad rakho

name = value ka matlab “is name ko ye value do”. Python variables names hote hain jo objects ko refer karte hain; labelled-box model beginner ke liye useful picture hai.
