Your first Python program: print, comments and indentation

Now that you know where Python runs, write a tiny program and learn how to read it. We will cover print(), strings, comments, statement order and indentation.

Real-life example

Imagine giving someone directions. The order matters: first open the door, then walk inside. In Python, statements run from top to bottom unless a condition, loop or function changes the flow. Indentation shows which instructions belong together.

Step-by-step explanation

  1. The line starting with # is a comment; Python does not execute it as an instruction.
  2. The assignment stores the text Asha under the name name.
  3. print() displays Hello and the value of name. By default it puts a space between objects.
  4. The if condition is True, so the indented print() line runs.

Python example

# This is a comment
name = "Asha"
print("Hello", name)
if name == "Asha":
    print("Welcome to Python!")

Expected output

Hello Asha
Welcome to Python!

Common mistake

Do not remove the indentation under if, for or while. Python uses indentation to know which statements are inside the block.

Remember this

Quotes mean text. # means comment. Indentation means “this line belongs to the block above”.
