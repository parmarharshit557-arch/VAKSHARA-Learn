Common list mistakes

List bugs aksar in-place methods ke return value ko galat samajhne ya iterate karte waqt same list remove/change karne se aate hain. Bade programs se pehle safe patterns samjhein.

Real-life example

Moving queue mein chalte hue beech se item remove karoge toh baaki positions shift ho sakti hain. Safer approach nayi filtered list banana hai.

Step-by-step samjhaav

  1. Comprehension original list ke har item ko visit karta hai.
  2. 2 se divide karne par remainder 0 ho wahi values rakhi jaati hain.
  3. Nayi list banti hai, original unchanged rehti hai.

Python example

numbers = [1, 2, 3, 4, 5, 6]
evens = [n for n in numbers if n % 2 == 0]
print(evens)
print(numbers)

Expected output

[2, 4, 6]
[1, 2, 3, 4, 5, 6]

Common mistake

Same list par loop chalate waqt usi list se items delete karna avoid karo; indices shift ho sakte hain.

Yaad rakho

Filtering mein loop ke beech original list edit karne ke bajaye nayi list banana aksar safer hai.
