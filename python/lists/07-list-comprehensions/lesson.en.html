List comprehensions

A list comprehension builds a new list from an iterable. It can transform each value and optionally keep only values that satisfy a condition.

Real-life example

A comprehension is a compact recipe: take each item from a collection, transform it, and optionally keep only items that pass a condition.

Step-by-step explanation

  1. for n in numbers visits each number.
  2. n * n creates the transformed value for squares.
  3. The if condition keeps only even numbers in evens.

Python example

numbers = [1, 2, 3, 4]
squares = [n * n for n in numbers]
evens = [n for n in numbers if n % 2 == 0]
print(squares)
print(evens)

Expected output

[1, 4, 9, 16]
[2, 4]

Common mistake

Do not squeeze a complicated multi-step program into one unreadable comprehension. Use a normal loop when clarity suffers.

Remember this

[expression for item in iterable if condition] — read it from left to right.
