List built-ins, membership and loops

Built-in functions answer common questions about lists, while membership tests and loops help inspect every value. enumerate() is useful when both the index and item are needed.

Real-life example

A list is a queue of tasks. len tells you how many tasks there are, in checks whether a task is present, and a loop visits each task.

Step-by-step explanation

  1. len() counts the list items.
  2. in returns True because quiz is present.
  3. The loop assigns each item to task and runs the body.

Python example

tasks = ["read", "revise", "quiz"]
print(len(tasks))
print("quiz" in tasks)
for task in tasks:
    print(task)

Expected output

3
True
read
revise
quiz

Common mistake

Do not call a list method and a built-in function as if they were the same. len(items) is a function; items.count(x) is a method.

Remember this

Functions receive the list: len(items). Methods belong to the list: items.count(x).
