Sorting and reversing lists

Sorting values ko order mein lagati hai; reversing sirf current order ulta karti hai. sort() original list ko in-place change karke None return karta hai; sorted() nayi sorted list deta hai.

Real-life example

Sorting books ko alphabetical order mein lagana hai. Reverse ka matlab current order ko ulta kar dena. Dono alag actions hain.

Step-by-step samjhaav

  1. sorted(scores) nayi sorted list return karta hai.
  2. sorted() ke baad original scores unchanged hai.
  3. sort() original list ko in-place sort karta hai.

Python example

scores = [40, 10, 30, 20]
print(sorted(scores))
print(scores)
scores.sort()
print(scores)

Expected output

[10, 20, 30, 40]
[40, 10, 30, 20]
[10, 20, 30, 40]

Common mistake

sort() list change karta hai aur None return karta hai. scores = scores.sort() mat likho.

Yaad rakho

sorted() nayi list deta hai; list.sort() existing list change karta hai.
