Create modules and use the main guard

Reusable code can live in a separate .py file and be imported elsewhere. The __name__ == "__main__" guard keeps selected code from running when the module is imported.

Real-life example

A reusable module is like a shared recipe card. The main guard is the note saying “cook this meal only when this card is run directly, not when another recipe borrows it.”

Step-by-step explanation

  1. A function definition is created when the module loads.
  2. When run directly, __name__ is "__main__" and the guarded block runs.
  3. When imported, the importing module name is used, so the guarded demo does not run.

Python example

# calculator_tools.py
def double(value):
    return value * 2

if __name__ == "__main__":
    print(double(5))

Expected output

10

Common mistake

Do not put all reusable functions inside the main guard. Define reusable functions at module level; keep only demo/startup code inside the guard.

Remember this

Define reusable tools first; protect only the direct-run demo with the main guard.
