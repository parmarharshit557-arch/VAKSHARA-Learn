BILKUL BASIC SE

Create modules and use the main guard

Reusable code ko alag .py file mein rakhkar doosri file mein import kar sakte hain. __name__ == "__main__" guard selected code ko module import hone par run hone se rokta hai.

Real-life example

Reusable module shared recipe card jaisa hai. Main guard note jaisa hai: is card ko directly run karne par main work karo, import hone par nahi.

Step-by-step samjhaav

  1. Module load hone par function definition ready hoti hai.
  2. File directly run ho toh __name__ "__main__" hota hai aur guard run hota hai.
  3. Import hone par __name__ module name hota hai; demo block automatically run nahi hota.

Python example

# calculator_tools.py
def double(value):
    return value * 2

if __name__ == "__main__":
    print(double(5))

Expected output

10

Common mistake

Saare reusable functions main guard ke andar mat rakho. Functions module level par; demo/startup code guard ke andar rakho.

Yaad rakho

Reusable tools pehle define karo; sirf direct-run demo ko main guard se protect karo.
