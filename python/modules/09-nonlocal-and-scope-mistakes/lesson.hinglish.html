nonlocal and scope mistakes

nonlocal nested functions mein nearest enclosing function ke name ko rebind karta hai. global module scope refer karta hai. Dono ko confuse karne se UnboundLocalError aur shadowing mistakes aa sakti hain.

Real-life example

Department ke andar team, aur us team ke andar chhoti team socho. nonlocal inner function ko enclosing function ka name update karne deta hai; global module-level name ko refer karta hai.

Step-by-step samjhaav

  1. make_counter count aur nested increase function create karta hai.
  2. nonlocal batata hai ki increase enclosing function ka count update kare.
  3. Returned function calls ke beech count ko remember rakhta hai.

Python example

def make_counter():
    count = 0
    def increase():
        nonlocal count
        count += 1
        return count
    return increase

counter = make_counter()
print(counter())
print(counter())

Expected output

1
2

Common mistake

global aur nonlocal alag scopes target karte hain. global module scope; nonlocal nearest enclosing function scope.

Yaad rakho

global = module level; nonlocal = enclosing function level.
