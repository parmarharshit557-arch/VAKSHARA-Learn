BILKUL BASIC SE

Random numbers, choices and seed

random module pseudo-random values generate karta hai aur sequence se selection/shuffle kar sakta hai. seed() same setup par sequence repeatable banata hai; security-grade randomness nahi deta.

Real-life example

random module shuffled deck se card nikalne jaisa hai. Ek card choose, bina replacement multiple select, ya deck shuffle kar sakte ho. Seed demo ko repeatable pseudo-random sequence deta hai.

Step-by-step samjhaav

  1. seed(7) pseudo-random sequence ka starting point set karta hai.
  2. choice() list se ek item select karta hai.
  3. shuffle() original list ko in-place rearrange karta hai; length 3 rehti hai.

Python example

import random
random.seed(7)
values = ["red", "blue", "green"]
print(random.choice(values))
random.shuffle(values)
print(len(values))

Expected output

A repeatable choice for this seed
3

Common mistake

random.shuffle(items) None return karta hai. Isse statement ki tarah call karo, phir changed list use karo.

Yaad rakho

choice = ek; sample = bina replacement multiple; shuffle = original order in-place change.
