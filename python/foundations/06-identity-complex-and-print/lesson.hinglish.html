Identity, swapping, complex numbers and output

Is topic group mein object identity, variable swapping, complex numbers aur print formatting samjhenge. Equality values compare karti hai; identity check karti hai ki dono references same object ko point karte hain ya nahi.

Real-life example

Equality poochti hai ki do notebooks mein content same hai ya nahi. Identity poochti hai ki dono names ek hi physical notebook ko point kar rahe hain ya nahi.

Step-by-step samjhaav

  1. a aur b ki values same hain, isliye == True hai.
  2. Dono alag list objects hain, isliye a is b False hai.
  3. c, a wale same object ko refer karta hai, isliye a is c True hai.
  4. sep print mein values ke beech ka separator badalta hai.

Python example

a = [1, 2]
b = [1, 2]
c = a
print(a == b)
print(a is b)
print(a is c)

name, age = "Asha", 18
print(name, age, sep=" - ")

Expected output

True
False
True
Asha - 18

Common mistake

Numbers ya strings ki value compare karne ke liye is use mat karo. == use karo; is ka common use value is None hai.

Yaad rakho

== poochta hai “value same?”; is poochta hai “object same?”
