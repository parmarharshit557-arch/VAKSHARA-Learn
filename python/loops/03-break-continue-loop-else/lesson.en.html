START FROM ZERO

break, continue and loop else

These statements change the normal loop flow. break exits the nearest loop, continue skips to the next iteration, and loop else runs only when the loop finishes without break.

Real-life example

In a classroom line, “skip this student for this activity” is like continue. “Stop the whole activity now” is like break.

Step-by-step explanation

  1. At 1, neither condition matches, so print 1.
  2. At 2, continue skips the remaining body and starts the next iteration.
  3. At 4, break exits the loop completely; 4 is not printed.

Python example

for number in range(1, 6):
    if number == 2:
        continue
    if number == 4:
        break
    print(number)

Expected output

1
3

Common mistake

break exits the nearest loop; continue skips only the current iteration. They do not do the same job.

Remember this

continue = skip this round; break = stop the loop.
