Loop basics: for, range and while

Loop instructions ko repeat karta hai. Sequence ya range ke items par chalna ho toh for; condition ke badalne tak repeat karna ho toh while use hota hai.

Real-life example

Loop attendance sheet par har student ka naam check karne jaisa hai. Har item ke liye same action repeat hota hai.

Step-by-step samjhaav

  1. range(1, 4) se 1, 2, 3 milte hain; 4 include nahi hota.
  2. for loop ek-ek value lekar print karta hai.
  3. while tab tak repeat hota hai jab tak count <= 3 True hai; count += 1 loop ko end ki taraf le jaata hai.

Python example

for number in range(1, 4):
    print(number)

count = 1
while count <= 3:
    print(count)
    count += 1

Expected output

1
2
3
1
2
3

Common mistake

while loop mein aisi value update honi chahiye jo condition ko ek din False bana de. Warna infinite loop ho sakta hai.

Yaad rakho

Sequence ho toh for useful; repeat karna condition par depend ho toh while useful.
