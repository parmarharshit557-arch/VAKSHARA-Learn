Logical operators and nested conditions

Logical operators combine conditions. A nested if places one decision inside another, so the second check happens only when the outer branch reaches it.

Real-life example

A nested decision is like entering a building: first the outside gate must open; only then do you reach the inner room and answer its question.

Step-by-step explanation

  1. The outer if checks has_id. It is True, so Python enters it.
  2. Inside, the inner if checks has_ticket. It is also True.
  3. The program prints Entry allowed.

Python example

has_id = True
has_ticket = True
if has_id:
    if has_ticket:
        print("Entry allowed")
    else:
        print("Ticket needed")
else:
    print("ID needed")

Expected output

Entry allowed

Common mistake

Indentation decides which if belongs inside another if. A wrongly indented else can attach to a different if.

Remember this

and = both checks must pass; or = at least one; nested if = one decision inside another.
