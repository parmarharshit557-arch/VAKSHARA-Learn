Truthy, falsy values and common mistakes

Python conditions mein sirf True/False hi nahi, doosri values bhi use ho sakti hain. 0, empty string aur empty collections falsy hoti hain; aksar baaki values truthy hoti hain. Branch order aur indentation bhi important hain.

Real-life example

Program ko kabhi check karna hota hai ki kuchh present hai ya nahi. Khali tokri mein kuchh nahi; ek apple wali tokri mein kuchh hai. Python mein empty/non-empty values ka truth value bhi hota hai.

Step-by-step samjhaav

  1. Empty list falsy hoti hai.
  2. Empty string falsy hoti hai.
  3. Non-empty list truthy hoti hai.

Python example

values = []
name = ""
subjects = ["Python"]
print(bool(values))
print(bool(name))
print(bool(subjects))

Expected output

False
False
True

Common mistake

Sirf truth check karna ho toh if value == True zaroori nahi. Aksar if value: ya if not value: likho.

Yaad rakho

Empty built-in containers aur empty text falsy hote hain; non-empty values truthy.
