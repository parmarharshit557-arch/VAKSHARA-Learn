Formatting, built-ins and string processing

f-strings braces ke andar expressions rakhkar readable formatting dete hain. Built-ins aur loops se text count, classify, reverse ya validate kar sakte hain.

Real-life example

Formatted message ready certificate ke blanks fill karne jaisa hai: sentence same rehta hai, name aur score correct jagah insert hote hain.

Step-by-step samjhaav

  1. f-string name ki value sentence mein insert karta hai.
  2. .1f score ko decimal ke baad ek digit tak format karta hai.
  3. for loop string ka har character ek-ek karke visit karta hai.

Python example

name = "Asha"
score = 92.456
print(f"{name} scored {score:.1f}%")

word = "python"
for letter in word:
    print(letter)

Expected output

Asha scored 92.5%
p
y
t
h
o
n

Common mistake

Opening quote se pehle f lagana mat bhoolo. Bina f ke {name} normal text rahega.

Yaad rakho

f-string = readable message + values; string loop = har iteration mein ek character.
