Variables: storing and reusing information

A variable gives a value a name so your program can use it again. Learn assignment, reassignment, naming rules, case sensitivity and Python’s dynamic typing before moving to detailed data types.

Real-life example

A variable is like a labelled box in your notes. The label is the name; what is currently inside is the value. You can replace the contents later, but the label lets you refer to it again.

Step-by-step explanation

  1. student_name is a name bound to the string value "Asha".
  2. score first refers to the integer 72.
  3. The next assignment replaces the value associated with score with 85.
  4. The final assignment binds score to a string. Python does not require you to declare the type first.

Python example

student_name = "Asha"
score = 72
print(student_name, score)

score = 85
print(score)

score = "excellent"
print(score)

Expected output

Asha 72
85
excellent

Common mistake

Do not use = when you mean “compare”. Use == for comparison. Also avoid vague names such as x when a descriptive name like total_marks makes the code easier to understand.

Remember this

name = value means “give this name this value”. Python variables are names bound to objects; the labelled-box picture is a beginner-friendly model.
