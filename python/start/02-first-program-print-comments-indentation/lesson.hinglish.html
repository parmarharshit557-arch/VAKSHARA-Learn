Your first Python program: print, comments and indentation

Ab jab pata hai Python kahan run hota hai, ek chhota program likhenge aur usko read karna seekhenge. print(), strings, comments, statement order aur indentation cover karenge.

Real-life example

Kisi ko directions dena socho. Order matter karta hai: pehle door kholo, phir andar jao. Python mein statements top-to-bottom run hote hain, jab tak condition/loop/function flow change na kare. Indentation batati hai kaunsi instructions ek block ka part hain.

Step-by-step samjhaav

  1. # se start hone wali line comment hai; Python ise instruction ki tarah execute nahi karta.
  2. Assignment name variable mein Asha text rakhta hai.
  3. print() Hello aur name ki value display karta hai. Default mein objects ke beech space deta hai.
  4. if condition True hai, isliye indented print() line run hoti hai.

Python example

# This is a comment
name = "Asha"
print("Hello", name)
if name == "Asha":
    print("Welcome to Python!")

Expected output

Hello Asha
Welcome to Python!

Common mistake

if, for ya while ke andar wali indentation remove mat karo. Python indentation se samajhta hai kaunsi statements block ke andar hain.

Yaad rakho

Quotes ka matlab text. # ka matlab comment. Indentation ka matlab “ye line upar wale block ke andar hai”.
