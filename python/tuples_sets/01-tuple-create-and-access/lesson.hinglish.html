Tuple basics and accessing items

Tuple ordered sequence hoti hai. Indexing, slicing, membership aur iteration support karti hai, lekin tuple ke item references ko reassign nahi kar sakte.

Real-life example

Tuple printed appointment card jaisa hai: fixed values order mein store hoti hain. Read kar sakte ho, lekin item in-place edit nahi kar sakte.

Step-by-step samjhaav

  1. Tuple teen values fixed order mein store karta hai.
  2. Index 0 se Asha aur -1 se last item CSE milta hai.
  3. len() teen items count karta hai.

Python example

record = ("Asha", 18, "CSE")
print(record[0])
print(record[-1])
print(len(record))

Expected output

Asha
CSE
3

Common mistake

One-item tuple ke liye comma chahiye: (5,). Sirf parentheses (5) integer ko group karte hain.

Yaad rakho

Tuple = ordered aur immutable. One-item tuple comma se banta hai.
