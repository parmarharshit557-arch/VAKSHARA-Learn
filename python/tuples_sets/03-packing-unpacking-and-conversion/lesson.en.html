Packing, unpacking and converting collections

Packing groups multiple values into a tuple. Unpacking assigns tuple items to matching variables. Lists and tuples can be converted when the program needs a different collection behaviour.

Real-life example

Packing is putting several values into one parcel. Unpacking is opening the parcel and assigning each item to its own labelled variable.

Step-by-step explanation

  1. The tuple stores three values.
  2. Unpacking assigns the first value to name, second to age and third to course.
  3. The number of target names must match the values unless starred unpacking is used.

Python example

student = ("Asha", 18, "CSE")
name, age, course = student
print(name)
print(age)
print(course)

Expected output

Asha
18
CSE

Common mistake

If you unpack three values into two names, Python raises ValueError. Use a starred target when one name should collect the remaining items.

Remember this

Packing groups values; unpacking distributes them into names.
