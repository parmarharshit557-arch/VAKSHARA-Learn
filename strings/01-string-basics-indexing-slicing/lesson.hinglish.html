String basics, immutability, indexing and slicing

String Unicode characters ki immutable sequence hoti hai. Indexing ek character nikalti hai; slicing start:stop:step se naya part banati hai aur stop index include nahi hota.

Real-life example

String letters ki row jaisi hai. Har character ki position hoti hai; ek character ya continuous part access kar sakte ho.

Step-by-step samjhaav

  1. Index 0 first character P ko point karta hai.
  2. Index -1 last character N ko point karta hai.
  3. Slice [1:4] index 1 se start aur 4 se pehle stop hota hai: Y, T, H.

Python example

word = "PYTHON"
print(word[0])
print(word[-1])
print(word[1:4])

Expected output

P
N
YTH

Common mistake

Strings immutable hoti hain. word[0] = "p" allowed nahi; method ya slicing se nayi string banao.

Yaad rakho

Index ek position deta hai; slicing range deti hai; stop index include nahi hota.
