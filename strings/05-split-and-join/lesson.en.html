Split and join strings

split() turns one string into a list of pieces. join() does the reverse: it combines an iterable of strings using the separator on which it is called.

Real-life example

split() is like cutting a sentence at spaces into word cards. join() is like arranging those cards and connecting them with a separator.

Step-by-step explanation

  1. split() returns a list of words.
  2. The list now has three string items.
  3. The separator string " | " joins those items into one string.

Python example

sentence = "learn Python daily"
words = sentence.split()
print(words)
print(" | ".join(words))

Expected output

['learn', 'Python', 'daily']
learn | Python | daily

Common mistake

join() is called on the separator string, and the items must be strings. Use map(str, values) when joining numbers.

Remember this

split: one string becomes a list; join: a list of strings becomes one string.
