User input and type conversion

input() reads what a user types and returns it as text. If a program needs a number, convert that text with int() or float() before doing arithmetic.

Real-life example

A form collects what a person writes. Even if someone writes 18 in an age box, the form first receives characters. Your program must convert that text into a number before doing maths.

Step-by-step explanation

  1. age_text is the string "18".
  2. int() converts that text into the integer 18.
  3. float() converts decimal text into 1.65, so arithmetic is now possible.

Python example

age_text = "18"
age = int(age_text)
height_text = "1.65"
height = float(height_text)

print(age + 2)
print(height + 0.10)

Expected output

20
1.75

Common mistake

input() does not automatically return a number. Convert it, and handle invalid input because int("eighteen") raises ValueError.

Remember this

input → text → convert → calculate. Remember this order.
