String concatenation and a first calculation

Plus sign strings ko join kar sakta hai aur numbers ko add. Text aur number alag types hain; combine karne se pehle zarurat ke hisaab se conversion karein.

Real-life example

Plus sign ka kaam uske dono taraf ki values par depend karta hai. Do strings ko jodta hai; do numbers ko add karta hai.

Step-by-step samjhaav

  1. first aur second strings hain, isliye + unhe join karta hai.
  2. length aur width numbers hain, isliye * multiplication karta hai.
  3. Rectangle ka area 12 × 4 = 48 square units hai.

Python example

first = "VAK"
second = "SHARA"
print(first + second)

length = 12
width = 4
area = length * width
print(area)

Expected output

VAKSHARA
48

Common mistake

"12" + "4" ka result "124" hai, 16 nahi. Arithmetic se pehle number mein convert karo.

Yaad rakho

Same symbol ka result type par depend karta hai: string + string join, number + number add.
