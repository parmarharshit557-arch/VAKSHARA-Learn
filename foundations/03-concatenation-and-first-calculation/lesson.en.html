String concatenation and a first calculation

The plus sign can join strings, while arithmetic operators calculate numeric values. Keep text and numbers distinct, and convert deliberately when combining them.

Real-life example

The plus sign has a job based on the values around it. With two pieces of text it joins them like two name tags; with two numbers it adds their amounts.

Step-by-step explanation

  1. first and second are strings, so + concatenates them.
  2. length and width are numbers, so * performs multiplication.
  3. The rectangle area is 12 × 4 = 48 square units.

Python example

first = "VAK"
second = "SHARA"
print(first + second)

length = 12
width = 4
area = length * width
print(area)

Expected output

VAKSHARA
48

Common mistake

"12" + "4" gives "124", not 16. Convert to numbers before arithmetic.

Remember this

Same symbol, different types: string + string joins; number + number adds.
