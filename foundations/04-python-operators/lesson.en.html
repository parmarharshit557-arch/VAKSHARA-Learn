Python operators

Operators let values participate in calculations, comparisons and logical decisions. Learn what each family returns, not just how its symbol looks.

Real-life example

An operator is like an action sign on a calculator. The values are the inputs, the operator tells Python what action to perform, and the expression produces a result.

Step-by-step explanation

  1. 250 × 2 calculates the total cost: 500.
  2. >= compares the total with 500 and returns True.
  3. and is True only because both comparisons are True.

Python example

price = 250
quantity = 2
total = price * quantity
print(total)
print(total >= 500)
print(total >= 500 and quantity > 1)

Expected output

500
True
True

Common mistake

Use == to compare values and = to assign a value. They are not interchangeable.

Remember this

Arithmetic calculates, comparison answers True/False, logical operators combine decisions.
