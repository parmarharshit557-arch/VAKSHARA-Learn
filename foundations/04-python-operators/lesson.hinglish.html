Python operators

Operators values par calculation, comparison aur logical decision karne dete hain. Sirf symbol nahi, har operator ka result samajhna important hai.

Real-life example

Operator calculator ke action button jaisa hai. Values inputs hain, operator action batata hai aur expression result deta hai.

Step-by-step samjhaav

  1. 250 × 2 se total 500 aata hai.
  2. >= total ko 500 se compare karta hai aur True deta hai.
  3. and tab True hai kyunki dono conditions True hain.

Python example

price = 250
quantity = 2
total = price * quantity
print(total)
print(total >= 500)
print(total >= 500 and quantity > 1)

Expected output

500
True
True

Common mistake

= value assign karta hai; == comparison karta hai. Dono ko interchange nahi kar sakte.

Yaad rakho

Arithmetic calculation karta hai, comparison True/False deta hai, logical operator decisions combine karta hai.
