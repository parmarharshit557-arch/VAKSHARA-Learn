Aliasing and copying lists

Assignment does not automatically copy a list. Two names can refer to the same object (an alias). Use copy(), slicing or list() for a shallow outer copy, and understand nested mutable objects.

Real-life example

Two labels on the same storage box do not create two boxes. If both labels point to one list, changing it through either name changes the same list.

Step-by-step explanation

  1. alias = original makes a second name for the same list object.
  2. Appending through alias changes original too.
  3. copy() creates a separate outer list, so appending to copy does not change original.

Python example

original = [10, 20]
alias = original
copy = original.copy()
alias.append(30)
copy.append(40)
print(original)
print(copy)

Expected output

[10, 20, 30]
[10, 20, 40]

Common mistake

A shallow copy separates the outer list but does not recursively copy nested lists inside it.

Remember this

Assignment creates another reference; copy() creates a separate outer list.
