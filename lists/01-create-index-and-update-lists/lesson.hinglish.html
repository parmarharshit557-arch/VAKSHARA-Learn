BILKUL BASIC SE

Create, index and update lists

List ordered aur mutable collection hoti hai. Index se item access aur valid position par item update kar sakte hain. List mein different data types ke values ho sakte hain.

Real-life example

List numbered shopping list jaisi hai. Position se item read kar sakte ho, replace kar sakte ho, aur items add/remove kar sakte ho.

Step-by-step samjhaav

  1. List mein teen items order mein store hain.
  2. Index 0 pehla item Maths select karta hai.
  3. Index 1 par Science replace hota hai; list mutable hoti hai.

Python example

subjects = ["Maths", "English", "Python"]
print(subjects[0])
subjects[1] = "Science"
print(subjects)

Expected output

Maths
['Maths', 'Science', 'Python']

Common mistake

Python indexing 0 se start hoti hai. Teen items ke valid positive index 0, 1, 2 hain; 1, 2, 3 nahi.

Yaad rakho

List = ordered + indexed + mutable. Positions zero se start hoti hain.
