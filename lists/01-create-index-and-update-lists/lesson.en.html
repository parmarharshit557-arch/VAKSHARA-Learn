Create, index and update lists

A list is an ordered, mutable collection. You can access its items by index and replace an item at a valid position. Lists can hold values of different types.

Real-life example

A list is like a numbered shopping list. You can read an item by its position, replace it, and add or remove items while shopping.

Step-by-step explanation

  1. The list stores three items in order.
  2. Index 0 selects the first item: Maths.
  3. Index 1 is replaced with Science; lists are mutable.

Python example

subjects = ["Maths", "English", "Python"]
print(subjects[0])
subjects[1] = "Science"
print(subjects)

Expected output

Maths
['Maths', 'Science', 'Python']

Common mistake

Python starts indexing at 0. For three items, valid positive indices are 0, 1 and 2—not 1, 2 and 3.

Remember this

List = ordered + indexed + mutable. Positions start at zero.
