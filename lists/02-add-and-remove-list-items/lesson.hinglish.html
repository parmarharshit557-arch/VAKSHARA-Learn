Add and remove list items

List ka size grow aur shrink kar sakta hai. append() ek object add karta hai, extend() iterable ke items add karta hai, insert() position par add karta hai; remove/pop/del/clear alag tarikon se remove karte hain.

Real-life example

Guest list socho. append ek guest end mein add karta hai; extend doosri group ke saare guests add karta hai; insert chosen position par rakhta hai. Removal methods alag situations handle karte hain.

Step-by-step samjhaav

  1. append() ek object end mein add karta hai.
  2. extend() second list ke har item ko add karta hai.
  3. pop() last item remove karke return karta hai.

Python example

items = ["pen", "book"]
items.append("bag")
items.extend(["bottle", "lunchbox"])
removed = items.pop()
print(items)
print(removed)

Expected output

['pen', 'book', 'bag', 'bottle']
lunchbox

Common mistake

append([4, 5]) poori list ko ek nested item banata hai; extend([4, 5]) 4 aur 5 ko alag add karta hai.

Yaad rakho

append ek item; extend multiple; insert position; pop remove karke value return.
