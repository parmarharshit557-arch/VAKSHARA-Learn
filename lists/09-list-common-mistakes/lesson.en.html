Common list mistakes

List bugs often come from confusing in-place methods with returned values, or modifying a list while iterating over it. Learn safer patterns before moving to larger programs.

Real-life example

When checking items in a moving queue, removing a person while walking through the queue can shift everyone’s position. A safer approach is to build a new filtered list.

Step-by-step explanation

  1. The comprehension visits the original list.
  2. Only values with remainder 0 after division by 2 are kept.
  3. A new list is created, so the original is unchanged.

Python example

numbers = [1, 2, 3, 4, 5, 6]
evens = [n for n in numbers if n % 2 == 0]
print(evens)
print(numbers)

Expected output

[2, 4, 6]
[1, 2, 3, 4, 5, 6]

Common mistake

Avoid deleting items from the same list while looping over it unless you fully understand the index-shifting effect.

Remember this

When filtering, a new list is often clearer and safer than editing the list mid-loop.
