Set operations and relationships

Set operations model mathematical relationships: union combines both sets, intersection keeps common items, difference keeps left-only items, and symmetric difference keeps items in exactly one set.

Real-life example

Two school clubs may have members in common. Union means everyone in either club; intersection means members in both; difference means members only in the first club.

Step-by-step explanation

  1. | combines all unique items from both sets.
  2. & keeps only shared items.
  3. - keeps items from the left set that are not in the right set.

Python example

python = {"Asha", "Rohan", "Mina"}
sql = {"Mina", "Dev"}
print(sorted(python | sql))
print(sorted(python & sql))
print(sorted(python - sql))

Expected output

['Asha', 'Dev', 'Mina', 'Rohan']
['Mina']
['Asha', 'Rohan']

Common mistake

Difference is directional: A - B may not equal B - A.

Remember this

Union = either; intersection = both; difference = left only; symmetric difference = exactly one side.
