Set basics and how sets differ from sequences

A set is an unordered collection of distinct hashable items. It removes duplicates and is useful for fast membership-style reasoning, but it does not support positional indexing or slicing.

Real-life example

A set is like a guest list where each name appears once. It answers “is this name present?” but it does not promise a numbered position for each name.

Step-by-step explanation

  1. The repeated name Asha is stored only once.
  2. There are three distinct names.
  3. Membership testing checks presence; set indexing is not supported.

Python example

attendees = {"Asha", "Rohan", "Asha", "Mina"}
print(len(attendees))
print("Rohan" in attendees)
empty_set = set()

Expected output

3
True

Common mistake

{} creates an empty dictionary, not an empty set. Use set() for an empty set.

Remember this

Set = unique items; no positional indexing; use set() for empty.
