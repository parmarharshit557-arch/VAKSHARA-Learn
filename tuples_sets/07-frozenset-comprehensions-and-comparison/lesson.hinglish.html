Frozenset, set comprehensions and collection comparison

frozenset immutable set hota hai. Set comprehension iterable se set banati hai. Lists aur sets ko combine karke duplicates remove ya common items find kar sakte hain; collection choose karne se pehle properties compare karein.

Real-life example

Normal set whiteboard list jaisa hai jise edit kar sakte ho. Frozenset laminated version jaisa hai: unique items hain par creation ke baad change nahi.

Step-by-step samjhaav

  1. Set comprehension har number ka square banata hai.
  2. Repeated input values set mein duplicate result nahi banate.
  3. frozenset unique items store karta hai, lekin mutate nahi hota.

Python example

numbers = [1, 2, 2, 3, 4]
unique_squares = {n * n for n in numbers}
locked = frozenset({"read", "write"})
print(sorted(unique_squares))
print("read" in locked)

Expected output

[1, 4, 9, 16]
True

Common mistake

Set comprehension mein expression hota hai; dictionary comprehension mein key: value pair hota hai.

Yaad rakho

set = unique aur mutable; frozenset = unique aur immutable.
