Modules and import styles

Module Python file hoti hai jo reusable code group karti hai. import se module ke names available hote hain; import style ke hisaab se unhe refer karne ka tareeka badalta hai.

Real-life example

Module toolbox jaisa hai. Har tool khud banane ke bajaye toolbox import karke required tool use karte ho.

Step-by-step samjhaav

  1. import math se module math naam se available hota hai.
  2. math.sqrt module ke through square-root function access karta hai.
  3. randint ko roll alias se import kiya; iska output har run mein badal sakta hai.

Python example

import math
import random
from random import randint as roll
random.seed(7)
print(math.sqrt(25))
print(roll(1, 6))

Expected output

5.0
3

Common mistake

Agar import math likha hai toh math.sqrt(25) call karo. Sirf sqrt(25) tab chalega jab sqrt direct import kiya ho.

Yaad rakho

Module import karo toh module.name; direct name import karo toh name directly.
