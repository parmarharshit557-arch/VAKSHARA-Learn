Common random module mistakes

random module ki common mistakes range boundaries, replacement rules aur in-place mutation ko galat samajhne se hoti hain. Har function kya return karta hai aur input change karta hai ya nahi, ye samjhein.

Real-life example

Random functions alag promises deti hain. Koi number, koi item choose, koi list change. Hamesha poochho: return kya hua aur original object change hua?

Step-by-step samjhaav

  1. shuffle() items ko in-place change karta hai.
  2. Ye nayi shuffled list return nahi karta; result None hai.
  3. Same list mein ab bhi teen elements hain.

Python example

import random
items = ["a", "b", "c"]
result = random.shuffle(items)
print(result is None)
print(len(items))

Expected output

True
3

Common mistake

randint(a, b) mein b include hota hai; randrange(a, b) mein b exclude. Use se pehle boundary rule dekho.

Yaad rakho

Return value aur side effect alag cheezein hain. Dono check karo.
