Common math module mistakes

Common mistakes include forgetting the math. prefix, passing unsupported types, mixing degrees with radians and assuming floating-point results are exact.

Real-life example

A calculator only gives the result for the button and units you provide. If you choose the wrong unit or wrong function, the answer may be valid Python but wrong for your problem.

Step-by-step explanation

  1. The angle begins in degrees.
  2. radians() converts it to the unit expected by math.sin().
  3. isclose() checks approximate equality, which is safer for floating-point results.

Python example

import math
angle_degrees = 90
angle_radians = math.radians(angle_degrees)
print(math.isclose(math.sin(angle_radians), 1.0))

Expected output

True

Common mistake

Do not assume decimal calculations always produce exact binary floating-point values. Use isclose() where approximate comparison is appropriate.

Remember this

Check import style, input type, units and floating-point precision.
