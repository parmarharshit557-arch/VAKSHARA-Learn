Random numbers, choices and seed

The random module produces pseudo-random values and selects or rearranges sequence elements. seed() makes a pseudo-random sequence repeatable for a given setup; it does not make randomness secure.

Real-life example

A random module is like drawing a card from a shuffled deck. You can choose one card, select several without replacement, or shuffle the deck. A seed lets a computer repeat the same pseudo-random sequence for a demo.

Step-by-step explanation

  1. seed(7) sets the starting point for the pseudo-random sequence.
  2. choice() selects one item from the list.
  3. shuffle() rearranges the original list in place; its length stays 3.

Python example

import random
random.seed(7)
values = ["red", "blue", "green"]
print(random.choice(values))
random.shuffle(values)
print(len(values))

Expected output

A repeatable choice for this seed
3

Common mistake

random.shuffle(items) returns None. Call it as a statement, then use the changed list.

Remember this

choice = one; sample = several without replacement; shuffle = change order in place.
