nonlocal and scope mistakes

nonlocal applies to nested functions: it rebinds a name in the nearest enclosing function scope. global points to module scope. Confusing these scopes causes common UnboundLocalError and shadowing mistakes.

Real-life example

Imagine a team inside a department. A nested function is a smaller team inside the first team. nonlocal lets the smaller team update a name owned by the enclosing team; global points outside to the module level.

Step-by-step explanation

  1. make_counter creates count and the nested increase function.
  2. nonlocal tells increase to update the count from the enclosing function.
  3. The returned function remembers that count between calls.

Python example

def make_counter():
    count = 0
    def increase():
        nonlocal count
        count += 1
        return count
    return increase

counter = make_counter()
print(counter())
print(counter())

Expected output

1
2

Common mistake

global and nonlocal target different scopes. global points to module scope; nonlocal points to the nearest enclosing function scope.

Remember this

global = module level; nonlocal = enclosing function level.
