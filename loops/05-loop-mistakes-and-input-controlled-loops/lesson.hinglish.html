Loop mistakes and input-controlled loops

Loop bugs aksar condition update na hone, range ki boundary galat hone ya update galat jagah hone se aate hain. Input-controlled loops mein sentinel, flag ya while True ke saath deliberate break use hota hai.

Real-life example

Repeat-until-exit menu shop counter jaisa hai jo customer ke “done” bolne tak open rehta hai. Loop ko clear stop signal chahiye.

Step-by-step samjhaav

  1. choice empty string se start hota hai, jo exit ke equal nahi hai.
  2. Loop body run hoti hai aur choice ko exit set karti hai.
  3. Condition dobara check hoti hai; ab False hai, isliye loop stop.

Python example

choice = ""
while choice != "exit":
    choice = "exit"
print("Menu closed")

Expected output

Menu closed

Common mistake

Control variable update karna bhoolna infinite loop ka common reason hai. List par iterate karte hue usi list ko casually modify mat karo.

Yaad rakho

Input-controlled loop mein initial value, repeated action aur stop condition tak pahunchne ka tareeka zaroori hai.
