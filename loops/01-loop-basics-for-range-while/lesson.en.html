Loop basics: for, range and while

A loop repeats instructions. Use for when iterating over a sequence or range, and while when repetition depends on a condition changing over time.

Real-life example

A loop is like checking every student name on an attendance sheet. You repeat the same action for each item instead of writing the action again and again.

Step-by-step explanation

  1. range(1, 4) produces 1, 2 and 3; the stop value 4 is not included.
  2. The for loop takes one value at a time and prints it.
  3. The while loop repeats while count <= 3 remains True; count += 1 moves it toward stopping.

Python example

for number in range(1, 4):
    print(number)

count = 1
while count <= 3:
    print(count)
    count += 1

Expected output

1
2
3
1
2
3

Common mistake

A while loop must change something that can eventually make its condition False. Otherwise it may run forever.

Remember this

for is handy when you have a sequence; while is handy when repetition depends on a condition.
