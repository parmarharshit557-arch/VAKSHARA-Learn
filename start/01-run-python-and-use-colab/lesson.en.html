Where and how can you run Python?

A Python program needs a place to be written and an environment that can run it. Your supplied learning material uses Google Colab notebooks, so we begin with cells and outputs, then explain the local-editor idea.

Real-life example

A notebook is like a workbook with separate boxes. You write one small experiment in a cell, run that cell and see the result directly underneath. You do not need to build a whole project before trying your first line.

Step-by-step explanation

  1. Open a Colab notebook and click a code cell.
  2. Type the two lines shown here.
  3. Run the cell using its Run button or Shift + Enter.
  4. The print output and the value of 2 + 3 appear below the cell.
  5. In a local setup, the same Python statements can be saved in a .py file and run with Python.

Python example

print("First cell")
print(2 + 3)

Expected output

First cell
5

Common mistake

If you run cells out of order, an earlier variable may not exist yet—or it may contain an older value. For a clean check, use Runtime → Run all in a fresh notebook session.

Remember this

Write in a cell → run the cell → read the output. A notebook lets you learn in small experiments.
