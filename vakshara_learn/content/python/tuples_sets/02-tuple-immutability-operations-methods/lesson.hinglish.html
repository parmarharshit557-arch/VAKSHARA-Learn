Tuple immutability, operations and methods

Tuple immutable hoti hai, lekin uske andar mutable object jaise list ka reference ho sakta hai. Concatenation, repetition, comparison, count() aur index() useful operations hain.

Real-life example

Tuple sealed record jaisa hai: inspect kar sakte ho aur usse naya tuple bana sakte ho, par stored position ko replace nahi kar sakte.

Step-by-step samjhaav

  1. count(4) batata hai 4 ek baar hai.
  2. index(7) position 1 batata hai.
  3. + naya tuple banata hai; original (4, 7) hi rehta hai.

Python example

point = (4, 7)
print(point.count(4))
print(point.index(7))
new_point = point + (9,)
print(new_point)

Expected output

1
1
(4, 7, 9)

Common mistake

Tuple ke slots replace nahi kar sakte, lekin tuple ke andar mutable list ho toh us list ke contents change ho sakte hain.

Yaad rakho

Tuple apne item references change nahi karta, lekin andar ki mutable object change ho sakti hai.
