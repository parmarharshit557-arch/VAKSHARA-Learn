Set basics and how sets differ from sequences

Set unordered collection hoti hai jisme distinct hashable items hote hain. Duplicates remove ho jaate hain. Membership ke liye useful hai, lekin indexing/slicing support nahi karti.

Real-life example

Set guest list jaisa hai jahan har naam ek baar hota hai. Ye “naam present hai?” ka answer deta hai, lekin numbered position promise nahi karta.

Step-by-step samjhaav

  1. Repeated Asha sirf ek baar store hota hai.
  2. Total teen unique names hain.
  3. Membership presence check karta hai; set indexing support nahi karta.

Python example

attendees = {"Asha", "Rohan", "Asha", "Mina"}
print(len(attendees))
print("Rohan" in attendees)
empty_set = set()

Expected output

3
True

Common mistake

{} empty dictionary banata hai, empty set nahi. Empty set ke liye set() use karo.

Yaad rakho

Set = unique items; positional indexing nahi; empty ke liye set().
