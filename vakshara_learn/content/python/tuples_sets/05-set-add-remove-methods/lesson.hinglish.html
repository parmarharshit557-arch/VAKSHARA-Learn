Adding and removing set items

Set mein ek item add karne ke liye add() aur iterable ke multiple items ke liye update() use hota hai. Value absent ho toh remove() KeyError de sakta hai; discard() nahi.

Real-life example

Set club membership list jaisa hai. add() member add karta hai, discard() present ho toh remove karta hai bina complain kiye, remove() absent item par error deta hai.

Step-by-step samjhaav

  1. add() Mina add karta hai agar pehle se present nahi.
  2. discard() Rohan present ho toh remove karta hai; absent ho toh error nahi.
  3. sorted() example ko fixed display order deta hai.

Python example

members = {"Asha", "Rohan"}
members.add("Mina")
members.discard("Rohan")
print(sorted(members))

Expected output

['Asha', 'Mina']

Common mistake

set.pop() arbitrary item remove karta hai; assume mat karo ki last ya particular item remove hoga.

Yaad rakho

add insert karta hai; remove ko item present chahiye; absent ho sakta hai toh discard safe hai.
