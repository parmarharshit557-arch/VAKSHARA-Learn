Common random module mistakes

Most random-module mistakes involve range boundaries, replacement rules or misunderstanding in-place mutation. Know what each function returns and whether it changes the input.

Real-life example

Random functions have different promises. One gives a number, one chooses an item, and one changes a list. Always ask: what comes back, and did the original object change?

Step-by-step explanation

  1. shuffle() changes items in place.
  2. It does not return a new shuffled list; result is None.
  3. The same list still contains three elements.

Python example

import random
items = ["a", "b", "c"]
result = random.shuffle(items)
print(result is None)
print(len(items))

Expected output

True
3

Common mistake

randint(a, b) includes b, while randrange(a, b) excludes b. Read the boundary rule before using either.

Remember this

Return value and side effect are different things. Check both.
