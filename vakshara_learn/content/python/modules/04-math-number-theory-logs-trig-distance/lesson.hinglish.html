Math module: number theory, logs, trigonometry and distance

math module number-theory helpers, logarithms, trigonometric functions aur distance calculations deta hai. Trigonometric functions radians use karte hain; zarurat par degrees convert karein.

Real-life example

Alag maths questions ke liye alag tools: GCD largest common factor, LCM first common multiple, trigonometry right triangle relationships calculate karti hai.

Step-by-step samjhaav

  1. gcd(18, 24) ka result 6 hai.
  2. lcm(4, 6) ka result 12 hai.
  3. factorial(5) = 5 × 4 × 3 × 2 × 1 = 120.
  4. pi/2 radians ko degrees mein convert karne par 90 aata hai.

Python example

import math
print(math.gcd(18, 24))
print(math.lcm(4, 6))
print(math.factorial(5))
print(round(math.degrees(math.pi / 2)))

Expected output

6
12
120
90

Common mistake

math.sin(), math.cos(), math.tan() radians expect karte hain. Degree input ko math.radians() se convert karo.
