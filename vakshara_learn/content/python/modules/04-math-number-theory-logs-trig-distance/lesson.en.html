Math module: number theory, logs, trigonometry and distance

The math module includes number-theory helpers, logarithms, trigonometric functions and distance calculations. Trigonometric functions use radians, so convert degrees when needed.

Real-life example

Different maths questions need different tools: GCD finds the largest shared factor, LCM finds the first shared multiple, and trigonometry measures relationships in a right triangle.

Step-by-step explanation

  1. gcd(18, 24) returns 6.
  2. lcm(4, 6) returns 12.
  3. factorial(5) multiplies 5 × 4 × 3 × 2 × 1 = 120.
  4. pi/2 radians converts to 90 degrees.

Python example

import math
print(math.gcd(18, 24))
print(math.lcm(4, 6))
print(math.factorial(5))
print(round(math.degrees(math.pi / 2)))

Expected output

6
12
120
90

Common mistake

math.sin(), math.cos() and math.tan() expect radians. Convert degree input with math.radians().

Remember this

Know which maths question you are answering; for trigonometry, check radians vs degrees.
