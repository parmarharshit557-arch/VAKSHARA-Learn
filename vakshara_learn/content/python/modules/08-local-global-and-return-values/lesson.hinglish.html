Local, global scope and return values

Scope batata hai ki variable name program ke kis region mein accessible hai. Function global name read kar sakta hai, local name bana sakta hai aur result return kar sakta hai. Unnecessary global state ke bajaye parameters aur return prefer karein.

Real-life example

Function chhoti work desk jaisa hai. Us desk par bana variable local hai. Global name desk ke bahar shared room mein hai. Return value finished result wapas dena hai.

Step-by-step samjhaav

  1. price parameter function call ke liye local hota hai.
  2. tax local variable hai; tax_rate module/global scope se read hota hai.
  3. return 105.0 caller ko wapas bhejta hai.

Python example

tax_rate = 0.05
def total_with_tax(price):
    tax = price * tax_rate
    return price + tax

print(total_with_tax(100))

Expected output

105.0

Common mistake

print() value screen par dikhata hai; return calling code ko value wapas deta hai. Dono same nahi.

Yaad rakho

Local function call ka hota hai; return result ko bahar bhejta hai.
