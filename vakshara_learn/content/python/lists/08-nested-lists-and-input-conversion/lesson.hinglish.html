Nested lists and input conversion

Nested list mein items ke roop mein doosri lists hoti hain, jo rows/columns represent kar sakti hain. split() typed text ko pieces mein todta hai; number chahiye toh har piece convert karein.

Real-life example

Nested list spreadsheet jaisi hai: outer list rows rakhti hai, har row columns. Ek cell tak pahunchne ke liye pehle row, phir column choose karo.

Step-by-step samjhaav

  1. marks[1] second row [90, 88] select karta hai.
  2. Uske baad [0] us row ka first value 90 select karta hai.
  3. split() text ke pieces banata hai; int() har piece ko number karta hai.

Python example

marks = [[80, 75], [90, 88]]
print(marks[1][0])
text = "12 15 18"
numbers = [int(part) for part in text.split()]
print(numbers)

Expected output

90
[12, 15, 18]

Common mistake

marks[1][0] ka matlab zero-based indexing mein row 1, column 0 hai. Ye first row/first column nahi.

Yaad rakho

Nested access = pehle outer index, phir inner index. Numeric work se pehle input pieces convert karo.
