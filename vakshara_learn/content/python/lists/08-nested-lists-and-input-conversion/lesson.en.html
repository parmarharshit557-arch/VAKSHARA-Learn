Nested lists and input conversion

A nested list contains lists as items, often representing rows and columns. split() turns typed text into pieces; convert each piece explicitly when numbers are needed.

Real-life example

A nested list is like a spreadsheet: the outer list contains rows, and each row contains columns. To reach one cell, choose a row and then a column.

Step-by-step explanation

  1. marks[1] selects the second row: [90, 88].
  2. The next [0] selects the first value of that row: 90.
  3. split() creates text pieces; int() converts each piece to a number.

Python example

marks = [[80, 75], [90, 88]]
print(marks[1][0])
text = "12 15 18"
numbers = [int(part) for part in text.split()]
print(numbers)

Expected output

90
[12, 15, 18]

Common mistake

marks[1][0] means row 1, column 0 using zero-based indexing. It does not mean first row, first column.

Remember this

Nested access = outer index first, inner index second. Convert input pieces before numeric work.
