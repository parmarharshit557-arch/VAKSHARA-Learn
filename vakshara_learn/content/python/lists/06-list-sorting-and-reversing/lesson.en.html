Sorting and reversing lists

Sorting orders values; reversing only changes their current order. sort() changes the list in place and returns None, while sorted() returns a new sorted list.

Real-life example

Sorting is arranging books alphabetically. Reversing is simply turning the current row around. They are not the same action.

Step-by-step explanation

  1. sorted(scores) returns a new sorted list.
  2. The original scores list is still unchanged after sorted().
  3. sort() changes the original list in place.

Python example

scores = [40, 10, 30, 20]
print(sorted(scores))
print(scores)
scores.sort()
print(scores)

Expected output

[10, 20, 30, 40]
[40, 10, 30, 20]
[10, 20, 30, 40]

Common mistake

sort() changes the list and returns None. Do not write scores = scores.sort().

Remember this

sorted() gives a new list; list.sort() changes the existing list.
