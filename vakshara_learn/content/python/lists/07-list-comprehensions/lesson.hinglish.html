List comprehensions

List comprehension iterable se nayi list banati hai. Ye har value transform kar sakti hai aur condition ke basis par selected values hi rakh sakti hai.

Real-life example

Comprehension compact recipe jaisi hai: har item lo, transform karo, aur chaaho toh sirf condition pass karne wale items rakho.

Step-by-step samjhaav

  1. for n in numbers har number visit karta hai.
  2. n * n transformed value create karta hai.
  3. if condition evens list mein sirf even numbers rakhti hai.

Python example

numbers = [1, 2, 3, 4]
squares = [n * n for n in numbers]
evens = [n for n in numbers if n % 2 == 0]
print(squares)
print(evens)

Expected output

[1, 4, 9, 16]
[2, 4]

Common mistake

Complex multi-step logic ko zabardasti ek unreadable comprehension mein mat likho. Clarity kam ho toh normal loop use karo.

Yaad rakho

[expression for item in iterable if condition] — left se right padho.
