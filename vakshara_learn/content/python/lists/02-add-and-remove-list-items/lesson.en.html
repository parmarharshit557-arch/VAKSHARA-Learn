Add and remove list items

Lists can grow and shrink. append() adds one object, extend() adds items from an iterable, insert() places an item at a position, and remove/pop/del/clear handle removal in different ways.

Real-life example

Think of a guest list. append adds one guest at the end; extend adds each guest from another group; insert places someone at a chosen position. Removal methods answer different questions.

Step-by-step explanation

  1. append() adds one object to the end.
  2. extend() adds each item from the second list.
  3. pop() removes and returns the last item.

Python example

items = ["pen", "book"]
items.append("bag")
items.extend(["bottle", "lunchbox"])
removed = items.pop()
print(items)
print(removed)

Expected output

['pen', 'book', 'bag', 'bottle']
lunchbox

Common mistake

append([4, 5]) adds the whole list as one nested item; extend([4, 5]) adds 4 and 5 separately.

Remember this

append one item; extend many items; insert at a position; pop removes and returns.
