List slicing

Slicing items ka range select karke nayi list return karti hai. Stop index exclude hota hai; step se items skip ya reverse direction mein read kar sakte hain.

Real-life example

Paanch seats ki row socho. Slice start aur stop positions se continuous seats select karta hai; stop wali seat include nahi hoti.

Step-by-step samjhaav

  1. [1:4] index 1 se start hota hai aur 4 se pehle rukta hai.
  2. [:3] default start 0 leta hai aur 3 se pehle rukta hai.
  3. [::2] har doosra item select karta hai.

Python example

colors = ["red", "blue", "green", "gold", "white"]
print(colors[1:4])
print(colors[:3])
print(colors[::2])

Expected output

['blue', 'green', 'gold']
['red', 'blue', 'green']
['red', 'green', 'white']

Common mistake

Stop index exclude hota hai. Isliye items[0:3] teen items deta hai, chaar nahi.

Yaad rakho

Slice syntax [start:stop:step] hai; stop boundary hai, selected index nahi.
