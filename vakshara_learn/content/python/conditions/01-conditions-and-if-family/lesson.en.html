Conditions and if statements

A condition is an expression Python can evaluate as True or False. if, else and elif let a program choose which block should run.

Real-life example

A condition is like a question at a school gate: “Do you have your ID card?” If the answer is yes, one action happens; otherwise another path may happen.

Step-by-step explanation

  1. Python checks marks >= 90. It is False.
  2. Python checks marks >= 60. It is True, so grade becomes B.
  3. The else block is skipped because one earlier branch matched.

Python example

marks = 72
if marks >= 90:
    grade = "A"
elif marks >= 60:
    grade = "B"
else:
    grade = "C"
print(grade)

Expected output

B

Common mistake

Put the most restrictive condition first. If you check marks >= 40 before marks >= 90, the A branch may never be reached.

Remember this

if checks the first path, elif checks another path, else catches the remaining case.
