Trace loops, counters and accumulators

Dry run mein har iteration ke baad variables ki value track karte hain. Counter events ki ginti rakhta hai; accumulator running result jaise total sum store karta hai.

Real-life example

Counter tally mark jaisa hai jo count rakhta hai. Accumulator running total hai jisme har nayi value add hoti rehti hai.

Step-by-step samjhaav

  1. total ko 0 se start karo.
  2. 2 add hua: total 2 ho gaya.
  3. 4 add hua: total 6; phir 6 add hua: total 12.

Python example

total = 0
for number in [2, 4, 6]:
    total += number
    print("running total:", total)
print("final:", total)

Expected output

running total: 2
running total: 6
running total: 12
final: 12

Common mistake

Agar total grow karna hai toh loop ke andar har baar 0 mat karo. Isse purana total erase ho jayega.

Yaad rakho

Counter aam taur par 1 se badhta hai; accumulator running result collect karta hai.
