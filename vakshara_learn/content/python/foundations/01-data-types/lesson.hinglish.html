Data types and Python values

Variable ek value ko refer karta hai. Value ka type batata hai ki us par kaunse operations meaningful hain. Pehle int, float, str, bool aur complex ko clearly pehchanna seekhenge.

Real-life example

School bag mein book, water bottle, name card aur yes/no permission slip ho sakti hai. Sab values hain, lekin unka type alag hai.

Step-by-step samjhaav

  1. 18 whole number hai, isliye iska type int hai.
  2. 1.65 mein decimal part hai, isliye float hai.
  3. Quotes ke andar text str hota hai; True ek bool value hai.

Python example

age = 18
height = 1.65
name = "Asha"
is_student = True

print(type(age).__name__)
print(type(height).__name__)
print(type(name).__name__)
print(type(is_student).__name__)

Expected output

int
float
str
bool

Common mistake

25 aur "25" ko same mat samjho. Pehla number hai jiske saath calculation ho sakti hai; doosra text hai.

Yaad rakho

Do sawal poochho: value kya hai, aur us value ka type kya hai?
