User input and type conversion

input() user ka typed data text ke roop mein deta hai. Agar calculation karni hai, toh int() ya float() se convert karke hi arithmetic karein.

Real-life example

Form mein user jo likhta hai, woh pehle text hota hai. Age box mein 18 likhne par bhi input() ko "18" string milti hai. Calculation se pehle number mein convert karna padta hai.

Step-by-step samjhaav

  1. age_text mein "18" text ke roop mein hai.
  2. int() us text ko integer 18 mein convert karta hai.
  3. float() decimal text ko 1.65 number banata hai; ab calculation ho sakti hai.

Python example

age_text = "18"
age = int(age_text)
height_text = "1.65"
height = float(height_text)

print(age + 2)
print(height + 0.10)

Expected output

20
1.75

Common mistake

input() apne aap number nahi deta. Convert karo; galat text par int("eighteen") ValueError dega.

Yaad rakho

input → text → conversion → calculation. Ye order yaad rakho.
