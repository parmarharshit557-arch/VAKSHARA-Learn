Formatting, built-ins and string processing

f-strings place expressions inside braces for readable formatting. Built-ins and loops help count, classify, reverse or validate text. These patterns are useful for real input cleaning.

Real-life example

A formatted message is like filling blanks in a ready-made certificate: the sentence stays the same, but the name and score are inserted in the right places.

Step-by-step explanation

  1. The f-string inserts the value of name.
  2. .1f formats score to one digit after the decimal point.
  3. The for loop visits each character in the string one at a time.

Python example

name = "Asha"
score = 92.456
print(f"{name} scored {score:.1f}%")

word = "python"
for letter in word:
    print(letter)

Expected output

Asha scored 92.5%
p
y
t
h
o
n

Common mistake

Do not forget the f before the opening quote. Without f, {name} is treated as ordinary text.

Remember this

f-string = readable message + values; a string loop = one character per iteration.
