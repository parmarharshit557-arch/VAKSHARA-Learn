Trimming and replacing text

Text cleaning mein aksar start/end ke unwanted characters hatate hain ya selected text replace karte hain. strip() ends par kaam karta hai; beech ke spaces remove nahi karta.

Real-life example

Ek label socho jiske edges par extra spaces hain aur beech mein typo hai. strip() edges clean karta hai; replace() text ka selected part badalta hai.

Step-by-step samjhaav

  1. strip() beginning aur end se whitespace remove karta hai.
  2. replace() selected text ko replace karke nayi string deta hai.
  3. Original raw string unchanged rehti hai.

Python example

raw = "  hello world  "
clean = raw.strip()
fixed = clean.replace("world", "Python")
print(clean)
print(fixed)

Expected output

hello world
hello Python

Common mistake

strip() sentence ke beech ki spaces remove nahi karta. Inner spaces normalize karne ke liye replace() ya split/join dekho.

Yaad rakho

Edges clean karne ke liye strip; selected text badalne ke liye replace.
