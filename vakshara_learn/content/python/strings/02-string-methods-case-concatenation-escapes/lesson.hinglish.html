String methods, case changes, joining and escape sequences

Python strings mein case change karne ke methods aur text jodne ke operators hote hain. Escape sequences newline aur tab jaise special characters ko represent karte hain.

Real-life example

String methods text tools jaise hain: koi case change karta hai, koi text join karta hai, aur escape sequence new line/tab add karta hai.

Step-by-step samjhaav

  1. upper() nayi uppercase string deta hai.
  2. title() title-case text deta hai.
  3. \n string ke andar new line represent karta hai.

Python example

name = "asha"
print(name.upper())
print(name.title())
message = "Hello\nPython"
print(message)

Expected output

ASHA
Asha
Hello
Python

Common mistake

String method nayi string return karta hai; original string ko in-place change nahi karta.

Yaad rakho

Methods text par kaam karte hain; transformed text rakhna ho toh returned value save karo.
